Khi nhiều quy tắc CSS cùng nhắm vào một phần tử nhưng đặt thuộc tính trái ngược nhau.

📊 Thang điểm Specificity

Quy tắc tính điểm trọng số: Thẻ (1) < Class (10) < ID (100) < Inline (1000).

⚡ Vũ khí !important

Khám phá từ khóa tối thượng ghi đè mọi quy tắc và cách dùng thông minh không gây lỗi hệ thống.

💡 Quy luật Thác đổ (Cascading): Chữ "C" đầu tiên trong CSS chính là Cascading (xếp tầng / thác đổ). Trình duyệt luôn tuân theo một bộ luật trọng tài cực kỳ công bằng để quyết định kiểu dáng nào sẽ chiến thắng hiển thị ra màn hình!

1. Luật ghi đè sau cùng
Nguyên tắc thứ tự xuất hiện
Khi hai bộ chọn CÙNG CẤP ĐỘ nhắm vào một phần tử
✨ Hiệu ứng: 0 / 3
HAI QUY TẮC CÙNG BỘ CHỌN THẺ P style.css
/* Khai báo trước: màu xanh */ p { color: blue; } /* Khai báo sau: màu đỏ */ p { color: red; }
🏆 Kết quả: Màu ĐỎ chiến thắng!

Nguyên tắc: Khi hai quy tắc có cùng độ ưu tiên, quy tắc nào được trình duyệt đọc sau cùng sẽ ghi đè (overwrite) lên quy tắc trước đó.

Đoạn văn <p> trên màn hình sẽ hiển thị màu ĐỎ (red)!

📌 Áp dụng cho tệp ngoài: Nếu có 2 tệp CSS ngoài cùng được liên kết, tệp nào đặt thẻ <link> ở phía dưới trong phần <head> sẽ có quyền ghi đè tệp ở phía trên!

2. Thang điểm trọng số
Bảng xếp hạng độ ưu tiên Specificity
Thang điểm quyết định: Thẻ (1) < Class (10) < ID (100) < Inline (1000)
✨ Hiệu ứng: 0 / 4
1. Bộ chọn Tên thẻ (Element Selector)
p, h1, div, a, button
1 ĐIỂM
2. Bộ chọn Lớp (Class Selector)
.tieude, .nutbam, .highlight
10 ĐIỂM
3. Bộ chọn Mã định danh (ID Selector)
#banner, #menu, #footer
100 ĐIỂM
4. CSS Nội tuyến (Inline Style)
<h1 style="color: red;">
1000 ĐIỂM

⚡ Ví dụ so găng: Một thẻ <p class="info"> được đặt: p { color: black; } (1 điểm) và .info { color: blue; } (10 điểm) → Màu xanh (.info) chiến thắng áp đảo vì có điểm ưu tiên cao hơn!

3. Quyền năng tối thượng
Từ khóa !important
Vũ khí phá vỡ mọi quy tắc thang điểm trong CSS
✨ Hiệu ứng: 0 / 3
SỬ DỤNG TỪ KHÓA !IMPORTANT CÚ PHÁP
p { color: red !important; } #tieude { color: blue; }
👑 Sức mạnh tối cao

Bất kỳ thuộc tính nào gắn đuôi !important sẽ lập tức vượt mặt mọi quy tắc khác, bất kể quy tắc kia là ID hay Style nội tuyến!

⚠️ Cảnh báo của SGK (Trang 93): Tránh lạm dụng !important bừa bãi vì nó sẽ phá vỡ quy luật tự nhiên của CSS, khiến việc sửa lỗi và bảo trì trang web sau này vô cùng khó khăn.
