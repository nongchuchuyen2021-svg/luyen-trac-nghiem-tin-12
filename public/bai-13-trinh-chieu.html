🎨 CSS là gì?

Tìm hiểu ngôn ngữ định dạng giúp trang web lột xác từ khung xương thô sơ thành giao diện màu sắc, bắt mắt.

📐 Cú pháp quy tắc CSS

Nắm vững cấu trúc kinh điển: Bộ chọn (Selector), Thuộc tính (Property) và Giá trị (Value).

🔗 3 Cách chèn CSS

Phân biệt và so sánh ưu/nhược điểm giữa: CSS nội tuyến, CSS nội bộ và CSS ngoài liên kết tệp.

💡 Quy luật phân vai kinh điển trong lập trình Web:
• HTML: Đóng vai trò là bộ khung xương và nội dung chữ nghĩa thô sơ.
• CSS: Đóng vai trò là quần áo, diện mạo, màu sắc, phong cách khoác lên bộ khung xương đó!

CÚ PHÁP CHUẨN CỦA MỘT QUY TẮC CSS (RULESET) CSS3
h1 { color: red; font-size: 24px; text-align: center; }
🎯 1. Bộ chọn (Selector)

Chỉ ra phần tử HTML nào sẽ được áp dụng kiểu định dạng (ở ví dụ trên là tất cả các thẻ tiêu đề <h1>).

⚙️ 2. Thuộc tính (Property)

Đặc tính thẩm mỹ muốn thay đổi: màu sắc (color), kích cỡ phông (font-size), căn lề (text-align)...

💎 3. Giá trị (Value)

Mức độ hoặc trạng thái cụ thể gán cho thuộc tính (màu đỏ: red, cỡ 24 điểm ảnh: 24px).

⚠️ Dấu câu bắt buộc: Toàn bộ các khai báo nằm trong cặp dấu ngoặc nhọn { }. Giữa thuộc tính và giá trị là dấu hai chấm :, và kết thúc mỗi dòng khai báo bắt buộc phải có dấu chấm phẩy ;.

3. Phương thức nhúng
Ba cách đưa CSS vào trang web
CSS nội tuyến (Inline), CSS nội bộ (Internal) và CSS ngoài (External)
✨ Hiệu ứng: 0 / 3
① CSS Nội Tuyến (Inline)

Viết trực tiếp vào thuộc tính style của từng thẻ HTML:

<h1 style="color: blue;"> Tiêu đề xanh </h1>

Nhược điểm: Rườm rà, lặp đi lặp lại mã nguồn, chỉ dùng khi sửa nhanh 1 chỗ.

② CSS Nội Bộ (Internal)

Viết trong cặp thẻ <style> nằm ở phần <head>:

<head> <style> h1 { color: red; } </style> </head>

Ưu điểm: Định dạng chung cho cả 1 trang web đơn lẻ, không cần tạo file ngoài.

③ CSS Ngoài (External) ⭐

Viết ra file .css riêng, liên kết bằng thẻ <link>:

<head> <link rel="stylesheet" href="style.css"> </head>

Chuẩn chuyên nghiệp: 1 file CSS dùng chung cho hàng trăm trang web của cả hệ thống!

🏆 Lời khuyên chuyên môn: Trong thực tế phát triển website, CSS ngoài (External CSS) là phương pháp tối ưu và được dùng nhiều nhất vì giúp tách biệt hoàn toàn nội dung (HTML) và thẩm mỹ (CSS), giúp mã sạch và dễ bảo trì.

1. Tách biệt Nội dung & Hình thức

HTML chuyên lo phần cốt lõi nội dung, còn CSS chuyên lo về thẩm mỹ, bố cục và màu sắc.

2. Chuẩn mực Cú pháp

Quy tắc CSS luôn gồm: selector { property: value; }. Nhớ kỹ dấu : và ;.

3. Ưu tiên CSS Ngoài

Nên dùng tệp CSS ngoài với thẻ <link> để tái sử dụng mẫu định dạng cho toàn bộ website.
