Thí Nghiệm Thú Vị: "1 Pixel (px) To Bằng Nào?"

🔍 Kéo thanh trượt điều chỉnh viền: 2px
h1 { border: 2px solid blue; }
Độ dày đường viền thay đổi thời gian thực theo số điểm ảnh pixel (px)
📐 Công thức SGK trang 71:

1 pixel = 2,54 / 96 cm ≈ 0,265 mm

Nghĩa là 96 pixel xếp liền nhau thì dài đúng bằng 1 inch (2,54 cm).
💡 Viền 2px trong SGK có ý nghĩa gì?
Đường viền dày 2px chỉ mảnh cỡ 0,5 milimét (nửa mm) — đủ để mắt người nhìn thấy rõ ràng, sắc nét mà không làm thô trang web.
✅ Ghi nhớ: Trong thiết kế web, px (pixel) là đơn vị đo chiều dài phổ biến nhất cho kích cỡ chữ, khoảng cách lề và khung viền.
04 · CÚ PHÁP CỐT LÕI
Giải Phẫu Quy Tắc CSS (CSS Rule Anatomy)
Bấm vào từng khối Lego để khám phá nhiệm vụ và các bẫy lỗi dấu câu thường gặp
Ý: 0 / 4
Bộ chọn: h1
{
Thuộc tính: color
:
Giá trị: red
;
}
👉 Nhấp vào một khối Lego ở trên để xem nhiệm vụ!
Một quy tắc CSS hoàn chỉnh luôn gồm 2 phần lớn: Bộ chọn (Selector) và Vùng mô tả (Declaration block).
1. Bộ chọn (Selector)
Trả lời câu hỏi: "Định dạng cho ai?" (chỉ định thẻ HTML nào bị tác động).
2. Thuộc tính (Property)
Trả lời câu hỏi: "Đổi cái gì?" (màu chữ color, cỡ chữ font-size, viền border...).
3. Giá trị (Value)
Trả lời câu hỏi: "Mức độ/Màu gì?" (red, 24px, solid blue, 15px...).
⚠️ Hai bẫy lỗi SGK cảnh báo: Giữa thuộc tính và giá trị là dấu hai chấm (:) (KHÔNG PHẢI dấu bằng =). Cuối mỗi khai báo bắt buộc phải có dấu chấm phẩy (;)!

💡 Dấu phẩy (,) có sức mạnh gì?
Khi viết h1, h2, h3 { color: red; }, chỉ bằng một dòng ngắn gọn, ta đổi màu đỏ cho cả 3 cấp tiêu đề mà không cần chép lại mã 3 lần!
⚠️ Để ý thẻ đoạn văn <p>:
Thẻ <p> không nằm trong danh sách bộ chọn nên nó hoàn toàn không bị ảnh hưởng. Bộ chọn chính là "màng lọc an toàn" của trang web!

🏠
1. CSS Trong (Internal)
Trong thẻ <style> tại <head>
• Đặt mẫu trong phần đầu tệp HTML.
• Phạm vi: Toàn bộ một trang web hiện thời.
• Thích hợp cho các trang có giao diện riêng biệt.
🌐
2. CSS Ngoài (External) ⭐
Tệp .css độc lập + Thẻ <link>
• Viết trong tệp .css riêng.
• Nối vào trang qua <link> hoặc @import.
• Phạm vi: Đồng thời nhiều trang web (cả website)!
🏷️
3. CSS Nội Tuyến (Inline)
Thuộc tính style="..." trong thẻ
• Viết trực tiếp vào từng thẻ mở.
• Phạm vi: Chỉ duy nhất một phần tử đó.
• SGK: Viết mất công nhưng trình duyệt áp dụng ngay!
🎯 Ghi nhớ so sánh: Muốn chỉnh 1 phần tử → Nội tuyến; muốn chỉnh 1 trang → CSS trong; muốn đồng bộ hàng trăm trang của cả website → Bắt buộc dùng CSS ngoài!
07 · ĐI SÂU CÁCH 1
Cách 1: CSS Trong (Internal CSS)
Đặt thẻ <style> ở đâu trong cấu trúc tệp HTML chuẩn để phát huy tối đa hiệu quả?
Ý: 0 / 3
TỆP index.html (CSS TRONG) HTML5
<!DOCTYPE html> <html> <head> <meta charset="utf-8"> <title>Lịch sử HTML</title> <!-- ĐẶT TOÀN BỘ CSS TRONG CẶP THẺ STYLE --> <style> h1 { color: red; } p { text-indent: 15px; } </style> </head> <body> <h1>Tiêu đề trang</h1> <p>Nội dung đoạn văn...</p> </body> </html>
📍 Vì sao phải đặt trong <head>?
Phần <head> được trình duyệt tải trước tiên. Khi đọc xong quy tắc CSS, trình duyệt mới vẽ các phần tử trong <body> ra màn hình, tránh hiện tượng trang bị nhấp nháy chữ xấu rồi mới đẹp!
✅ Ưu điểm & Nhược điểm:
• Ưu điểm: Gọn gàng trong 1 tệp duy nhất, tiện gửi nộp bài tập.
• Nhược điểm: Trang web thứ hai muốn dùng lại phải sao chép toàn bộ khối <style>, khi sửa phải mở từng tệp sửa lại!

⚡ Nhận định đặc sắc trong SGK trang 74:

Nghĩa là: Người viết code thì mất công gõ lặp đi lặp lại, nhưng trình duyệt khi quét tới thẻ đó thì áp dụng tức thì mà không cần tra cứu lên phần <head> hay đợi tải tệp ngoài.

Chỉ dùng khi cần sửa nóng tạm thời 1 phần tử cá biệt, hoặc khi gửi email marketing dạng HTML. Không bao giờ dùng cho cả website vì sẽ tạo ra mã nguồn hỗn loạn!

Bác Sĩ CSS: Bắt Bệnh 4 Lỗi Cú Pháp Học Sinh Hay Mắc

❌ Ca 1: Dùng dấu bằng thay dấu hai chấm
h1 { color = red; } /* SAI TOÁT */
💊 Đơn thuốc: CSS không phải phép gán biến toán học. Bắt buộc dùng dấu hai chấm: h1 { color: red; }.
❌ Ca 2: Quên dấu chấm phẩy (;) kết thúc
p { color: blue font-size: 20px; } /* LỖI LIÊN HÀNG */
💊 Đơn thuốc: Trình duyệt sẽ coi `blue font-size: 20px` là 1 chuỗi vô nghĩa và bỏ qua luôn cả 2 thuộc tính! Luôn kết thúc bằng ;.
❌ Ca 3: Thừa ngoặc nhọn <> ở bộ chọn
<h1> { color: red; } /* SAI CÚ PHÁP BỘ CHỌN */
💊 Đơn thuốc: Trong CSS, bộ chọn theo tên thẻ chỉ viết tên trần: h1 { ... }, không bao giờ được kẹp dấu < >!
❌ Ca 4: Đặt thẻ <link> ở ngoài <head>
<body> ... <link href="style.css"> </body>
💊 Đơn thuốc: Thẻ <link> liên kết tài nguyên ngoại tuyến chuẩn luôn luôn phải nằm gọn gàng bên trong phần tử <head>!

1. Ngôn ngữ độc lập
CSS có cú pháp riêng, tách rời khỏi HTML, dùng để thiết lập mẫu định dạng nhanh chóng và tiện lợi.
2. Cú pháp kinh điển
Cấu trúc: Bộ chọn { Thuộc tính: Giá trị; }. Nhiều quy định ngăn bằng ;, nhiều thẻ ngăn bằng ,.
3. Ba phương thức
CSS trong (thẻ style ở head), CSS ngoài (tệp .css qua link), CSS nội tuyến (style trong thẻ).
4. Cơ chế xếp tầng (Cascade)
Nội tuyến thắng CSS trong; CSS trong thắng CSS ngoài. Quy tắc nào gần phần tử hơn sẽ thắng!
